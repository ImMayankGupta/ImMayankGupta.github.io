## Curated free APIs

Below is a hand-picked list of APIs I use for demos, framework tutorials, and interview practice.

### No authentication required

- **[JSONPlaceholder](https://jsonplaceholder.typicode.com/)** — fake REST API for testing
- **[ReqRes](https://reqres.in/)** — hosted REST + mock users
- **[The Cat API](https://thecatapi.com/)** — cat images & facts
- **[Open-Meteo](https://open-meteo.com/)** — weather forecasts, no key

### AI & LLM APIs (free tiers)

- **[Groq](https://console.groq.com/)** — free LLM inference (very fast)
- **[Hugging Face Inference API](https://huggingface.co/inference-api)** — thousands of models
- **[Cohere](https://cohere.com/)** — trial credits for embeddings & chat

### Datasets

- **[Kaggle Datasets](https://www.kaggle.com/datasets)**
- **[Google Dataset Search](https://datasetsearch.research.google.com/)**
- **[Hugging Face Datasets](https://huggingface.co/datasets)**
